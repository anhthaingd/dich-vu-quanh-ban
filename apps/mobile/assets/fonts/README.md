# Product font

Be Vietnam Pro, the font used by `ui-ux/prototype/src/style.css` (Storybook).
Regular, SemiBold and Bold are bundled for offline native/web use through `expo-font`.
Source: https://github.com/google/fonts/tree/main/ofl/bevietnampro (retrieved 2026-10-08).
License: SIL Open Font License 1.1, preserved in `OFL.txt`.
Japanese glyphs fall back to the platform font. `AppText` maps weights to the bundled family.
